# BillFlow - Système de Gestion de Facturation Professionnel

BillFlow est une solution moderne et complète de gestion de facturation, conçue pour simplifier la création, le suivi et la gestion des factures et des clients. Le système se compose d'une interface frontend réactive en React et d'un backend robuste en Node.js, offrant une expérience utilisateur fluide et professionnelle.

## 🚀 Fonctionnalités Clés

- **Modèles de Factures Professionnels** : Design soigné correspondant aux standards de l'industrie, optimisé pour l'impression.
- **Gestion Complète des Factures (CRUD)** : Création, lecture, mise à jour et suppression de factures en toute simplicité.
- **Gestion des Clients** : Centralisation des informations clients pour une facturation rapide et précise.
- **Types de Documents Multiples** : Prise en charge des factures proforma, définitives et des notes de crédit (avoirs).
- **Export PDF & Impression** : Génération de documents PDF professionnels prêts à être envoyés par email ou imprimés.
- **Design Responsive** : Interface optimisée pour une utilisation sur ordinateur, tablette et mobile.
- **Validation en Temps Réel** : Contrôle des données saisies pour éviter les erreurs de facturation.
- **Interface Moderne** : Développée avec Tailwind CSS et Shadcn/UI pour une esthétique premium.

## 📋 Structure du Projet

Le projet est divisé en deux parties principales :

- **billflow-backend** : Serveur API développé avec Node.js, Express et TypeScript.
    - Gère la logique métier, l'accès à la base de données MySQL et l'authentification.
- **billflow-client-scribe** : Application frontend développée avec React et Vite.
    - Interface utilisateur interactive pour la gestion quotidienne des opérations de facturation.

## 🛠️ Stack Technique

- **Frontend** : React, Vite, Tailwind CSS, Shadcn/UI, Zod (validation).
- **Backend** : Node.js, Express, TypeScript, Sequelize (ORM).
- **Base de données** : MySQL / SQLite (pour le développement local).
- **Déploiement** : Support Docker pour une mise en production simplifiée.

## 🎯 Utilisation et Avantages

BillFlow permet aux entreprises de :
1. **Gagner du temps** grâce à l'automatisation de la création de factures.
2. **Maintenir une image professionnelle** avec des modèles de documents élégants.
3. **Suivre précisément leur activité** grâce à une liste centralisée et filtrable des transactions.
4. **Réduire les erreurs** grâce à des formulaires de saisie intelligents et validés.
